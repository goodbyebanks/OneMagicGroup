02 / The origin

Before the group had a name, there was a game.

OneMagic Esports was the first operating chapter. PUBG tournaments became more than competition: they created the first cash flow, the first team structure and the first lessons in management. The esports operation is now on hold — but the mindset stayed.

That same principle drives the group today: start with what you have, build intelligently, reinvest, and keep moving.
