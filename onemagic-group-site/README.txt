ONEMAGIC GROUP — WEBSITE

A single-page, cinematic OneMagic Group website inspired by the supplied reference video: dark premium canvas, vivid blue/cyan/violet gradients, motion, 3D wireframe globe, particle field, animated marquee, reveal-on-scroll sections and responsive layouts.

FILES
- index.html — complete website; CSS and JavaScript are embedded.

RUN
Open index.html in a modern browser. The 3D scene uses Three.js from jsDelivr, so an internet connection is required for the 3D layer and Google Fonts.
